<img src="/logo/128x128/groupdocs-search-net.png" alt="groupdocs-search-net-home" align="left" style="width:110px; margin: 0 30px 30px 0"/> **Welcome to GroupDocs.Search for .NET**  
GroupDocs.Search for .NET is a document search API. It extracts text and metadata from documents and performs advanced indexing and search operations, including fuzzy and synonym search. The API supports full-text search based on indexes: all documents that have at least one match of the searched words or phrases are listed in the result.
