Step-by-step scenarios for searching documents with AI agents over MCP — each page answers one real question completely, with the setup, the calls the agent makes, the results it gets back (captured from the server), and the exact prompt:

* [How to search documents with AI agents using MCP]({{< ref "search/mcp/use-cases/search-documents-with-ai-agents.md" >}}) — start here: the index → search → quote pattern, which tool for which question, and the query language.

* [How to get the matching passages instead of reading whole files]({{< ref "search/mcp/use-cases/quote-matching-passages-not-whole-files.md" >}}) — grounded answers on a small context: fragments, the termsBefore/termsAfter dial, and variants.

* [How to search email archives and attachments with an AI agent, locally]({{< ref "search/mcp/use-cases/search-email-archives-locally.md" >}}) — PST, OST, MSG and EML — including the text of attached documents.
* [How to find documents by date range, amount and file name with an AI agent]({{< ref "search/mcp/use-cases/find-documents-by-date-and-amount.md" >}}) — content: daterange(…), number ranges, file-name words — and the file-date trap.
