GroupDocs provides unlimited free technical support for all of its products. Support is available to all users, including evaluation. The support is provided at [Free Support Forum](https://forum.groupdocs.com/) and [Paid Support Helpdesk](https://helpdesk.groupdocs.com/).

{{< alert style="info" >}}

Please note that GroupDocs does not provide technical support over the phone. Phone support is only available for sales and purchase questions.

{{< /alert >}}

## GroupDocs Free Support Forum

If you need help with GroupDocs.Search, consider the following:

* Make sure you are using the latest GroupDocs.Search version before reporting an issue. See the [release notes](https://releases.groupdocs.com/search/python-net/release-notes/) to find out about the latest version.
* Have a look through the forums, this documentation, and the [API Reference](https://reference.groupdocs.com/search/python-net/) before reporting an issue - perhaps your question has already been answered.
* Post your question at [GroupDocs.Search Free Support Forum](https://forum.groupdocs.com/c/search/16), and we'll assist you. Questions are answered directly by the GroupDocs.Search development team.
* When expecting a reply on the forums, please allow for time zone differences.

## Paid Support Helpdesk

The paid support issues have higher priority compared to the free support requests.

* Post your question at the [Paid Support Helpdesk](https://helpdesk.groupdocs.com/) to set higher priority for the issue.

## Report an Issue or Feature Request

When posting your issue, question, or feature request with GroupDocs.Search, follow these simple steps to make sure it is resolved in the most efficient way:

* Include the original document and possibly the code snippet that is causing the problem. If you need to attach a few files, zip them into one. It is safe to attach your documents to GroupDocs.Forums because only you and the GroupDocs developers will have access to the attached files.
* Add information about the environment you are facing the issue in: the operating system, the Python version (`python --version`) and the package version (`pip show groupdocs-search-net`).
* Try to report one issue per thread. If you have another issue, question, or feature request, please report it in a separate thread.
